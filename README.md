Images and videos for my portfolio: **[aminportfolio.webflow.io](https://aminportfolio.webflow.io)**

This repository is not a project on its own. It is where the portfolio loads its pictures from, so everything here is on the site: case study screens and slides for COSH!, the Harbour Operations Platform and Chill Guy, the Expense Tracker, and the industrial and social design projects.

## Keeping the site working

The site links to these files by name, so a renamed or moved file disappears from the portfolio.

- Add new files; do not rename, move or overwrite the ones already here.
